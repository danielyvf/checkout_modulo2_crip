# Cifra de César em Python

Implementação simples e educacional em Python da clássica **Cifra de César** (técnica de substituição por deslocamento), desenvolvida para fins de estudo em Segurança da Informação e Criptografia.

## Sobre o Projeto

Este script demonstra o funcionamento de uma cifra simétrica básica, onde uma chave numérica (deslocamento) é utilizada tanto para criptografar quanto para descriptografar mensagens. O código preserva letras maiúsculas/minúsculas e mantém caracteres especiais (espaços, pontuações e números) inalterados.

## Como Executar

Certifique-se de ter o [Python](https://www.python.org/) instalado em sua máquina.

1. Clone o repositório ou baixe o arquivo `script.py`.
2. Abra o terminal na pasta do projeto.
3. Execute o script:

```bash
python script.py
